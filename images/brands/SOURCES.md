# Platform artwork

These PNG files use actual platform artwork, not manually recreated logos.

| File | Official source |
| --- | --- |
| `steam.png` | https://store.fastly.steamstatic.com/public/shared/images/header/logo_steam.svg |
| `app-store.png` | https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg |
| `google-play.png` | https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png |
| `itch-io.png` | https://static.itch.io/images/logo-white-new.svg |

The supplied Steam, App Store and itch.io artwork was rasterised to PNG at 480 px wide, preserving its proportions and colours. Google Play uses the supplied PNG with transparent outer padding removed. Assets are served locally.

Brand resources: [Steam](https://partner.steamgames.com/doc/marketing/branding), [Apple](https://developer.apple.com/app-store/marketing/guidelines/), [itch.io](https://itch.io/press-kit).
